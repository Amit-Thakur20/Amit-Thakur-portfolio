# Amit Thakur — Portfolio

Personal portfolio for Amit Thakur, Product Manager. Plain HTML/CSS/JS — no build step, no dependencies.

## Preview

```bash
python3 scripts/dev-server.py   # http://localhost:8000
```

## Deploy

GitHub Pages serves the repo root of `main` on every push (`.nojekyll` disables Jekyll).

Live: https://amit-thakur20.github.io/Amit-Thakur-portfolio/
